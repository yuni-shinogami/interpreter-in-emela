# interpreter-in-emela

Thorsten Ball 著『[Go言語でつくるインタプリタ](https://www.oreilly.co.jp/books/9784873118222/)』（原題 *Writing An Interpreter In Go*）の Monkey 言語のインタプリタを、[Emela](https://github.com/emela-lang/emela) で書いています。

プログラミング言語の実装を学ぶための、学習用のプロジェクトです。本は「何を作るか」の参考にしていて、コードは自分で書いています。Go 版をそのまま移すのではなく、Emela に合った書き方（書き換えないデータ、`enum` とパターンマッチ、型付きエラー、エフェクト）を選んでいるので、設計は本と違うところがあります。

## 進み具合

始めたばかりです。

- [ ] 字句解析（1章）
- [ ] 構文解析（2章）
- [ ] 評価（3章）
- [ ] 文字列・配列・ハッシュ・組み込み関数（4章）
- [ ] REPL

## 動かし方

Emela は `main` からビルドしたものが必要です（`Std.Process` など、まだリリースされていない機能を使います）。最後に確認したのは `emela 0.27.1+43b5f0f` です。

```sh
emela test   # テストを実行する
emela run    # プログラムを実行する
```

## レビュー歓迎

言語の実装や Emela に詳しい方からの意見をお待ちしています。特に見てほしいのは次の点です。

- Emela らしい書き方になっているか
- 字句解析器と構文解析器の状態を、書き換えずにどう扱うか（残りの入力を受け渡すか、`Std.State` を使うか）
- 書き換えない環境で、再帰するクロージャをどう実現するか
- 本格的な処理系なら違うやり方をするところ

Issue か、コミットやプルリクエストへのコメントでお願いします。
